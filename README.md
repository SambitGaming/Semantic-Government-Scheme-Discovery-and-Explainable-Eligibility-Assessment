# Smart Government Scheme Assistant

## Project

Semantic Government Scheme Discovery and Explainable Eligibility Assessment

## Description

An explainable government scholarship discovery and eligibility guidance platform for education-related schemes in India.

The project evaluates lexical and semantic retrieval methods and provides traceable eligibility guidance using version-controlled deterministic rules.

## Research Components

* Government scholarship corpus
* BM25 retrieval
* Sentence embedding retrieval
* Retrieval benchmark
* Retrieval evaluation
* Explainable eligibility rules engine
* Rule version management
* Government source verification

## Initial Corpus

50–75 government scholarship and education-related schemes.

## Status

Day 1 — Research foundation and project setup

## Important

The platform provides guidance only.

It does not officially approve, verify, or submit government applications.
